Manual de uso - Loja de Hardware

1. Para que serve

O programa cadastra os produtos da loja em um banco de dados MySQL. Para cada produto sao registrados o nome, a marca, o tipo, o modelo, a quantidade em estoque e uma foto.

2. Cadastrar um produto

  1. Clique em Novo.
  2. Preencha os campos e, se quiser, clique em Escolher foto.
  3. Clique em Salvar.

3. Outras opcoes

  • Editar / Excluir: selecione um produto na tabela antes.
  • Buscar e Tipo: filtram a tabela.
  • Arquivo > Limpar campos: esvazia os campos.
  • Arquivo > Sair: encerra o programa.
  • Ajuda > Sobre: mostra os autores e a versao.

4. Mensagens de erro

Preencha o tipo do produto.Digite o tipo.
Preencha o modelo.Digite o modelo.
A quantidade em estoque deve ser um numero inteiro!Use apenas digitos.
A quantidade em estoque nao pode ser negativa.Informe 0 ou mais.

5. Atalhos de teclado

  • F1 - abre este manual
  • Ctrl+L - limpar campos
  • Ctrl+Q - sair

6. Requisitos

  • Java 8 ou superior;
  • MySQL em execucao, com o banco hardware_store.
